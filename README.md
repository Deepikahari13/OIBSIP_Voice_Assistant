# BMI Calculator

A beginner-level Python BMI Calculator that calculates Body Mass Index using weight and height and displays the corresponding BMI category.

## Features

- Accepts weight in kilograms
- Accepts height in meters
- Calculates BMI
- Displays BMI up to 2 decimal places
- Shows BMI category
- Handles invalid numeric input
- Handles non-positive values

## Formulas

BMI = weight/(height**2)

## BMI Categories

- Underweight: BMI below 18.5
- Normal: BMI 18.5 to 24.9
- Overweight: BMI 25 to 29.9
- Obese: BMI 30 or above

## Technologies Used

- Python
