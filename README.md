# Voice Assistant

A beginner - level Python Voice Assistant that can listen to voice commands and respond using speech.

## Features

-Voice input
-Speech recognition
-Greeting response
-Current time and date
-Google web search
-Text-to-speech
-Basic error handling

## Technologies Used

-Python
-SpeechRecognition
-PyAudioWPatch
-pyttsx3

## How to Run

```bash
python voice_assistant.py

## Example Commands

-"Hello"
-"What is the time?"
-"What is today's date?"
-"Search Python tutorial"
