# Random Password Generator

A beginner-level Python tool that generates random passwords based on user-defined criteria.

## Features

- Allows the user to specify password length
- Minimum password length of 8 characters
- Supports uppercase letters
- Supports lowercase letters
- Supports numbers
- Supports symbols
- Requires at least 2 character types
- Generates a random password
- Validates invalid inputs
- Allows generating another password without restarting the program

## Technologies Used

- Python
- Random module
- String module

## How to Run

```bash
python password_generator.py
